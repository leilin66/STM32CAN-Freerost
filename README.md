\# 基于 FreeRTOS 和 CAN 总线的分布式测控系统



\## 项目简介

使用 STM32F407（主机）和 STM32F103（从机）搭建了一个 CAN 总线通信系统。

主机运行 FreeRTOS，通过自定义应用层协议实现对从机的远程控制和传感器数据采集。



\## 硬件平台

\- 主机：STM32F407VET6 + TJA1050

\- 从机：STM32F103C8T6 + TJA1050 + 光敏传感器

\- 调试工具：USB-CAN 分析仪、逻辑分析仪



\## 软件架构

| 任务 | 功能 | 频率 |

| Task\_CAN\_Tx | 定时发送远程帧查询传感器 | 每秒 |

| Task\_CAN\_Rx | 轮询 FIFO 接收 CAN 数据 | 实时 |

| Task\_KeyScan | 按键扫描，控制 CAN 启停和 LED | 50Hz |

| Task\_Printf | 消费打印队列，串口输出 | 阻塞等待 |



\## 通信协议

| CAN ID | 方向 | 帧类型 | 说明 |

| 0x001 | 主机→从机1 | 远程帧 | 查询光敏传感器 |

| 0x011 | 从机1→主机 | 数据帧 | 回传光敏值 |

| 0x002 | 主机→从机2 | 远程帧 | 查询热敏传感器 |

| 0x022 | 从机2→主机 | 数据帧 | 回传热敏值 |

| 0x501-0x505 | 主机→从机 | 数据帧 | 控制 LED 亮灭 |

| 0x999/0x998 | 主机→从机 | 远程帧 | CAN 启停通知 |



\## 技术亮点

\- 自定义 CAN 应用层协议，支持远程帧触发数据上报

\- 环形缓冲区解决 CAN 中断高频接收下的数据覆盖问题

\- FreeRTOS 消息队列解耦数据接收和串口打印

\- 低优先级打印任务 + 直接写寄存器，避免阻塞通信任务



\## 快速上手

1\. 用 CubeIDE 打开工程，编译

2\. 分别烧录到 F407 主机和 F103 从机

3\. 连接 CAN 总线（TJA1050 模块），两端各加 120Ω 终端电阻

4\. 主机串口 115200 波特率，可看到传感器数据



\## 调试记录

\- DHT11 单总线时序严格，最终改用光敏传感器

\- CAN 过滤器配置为全收模式后，可正常接收从机数据

\- FreeRTOS 下 `HAL\_Delay` 会阻塞调度器，统一替换为 `osDelay`

\- 中断回调中不能调用 `printf`，改用消息队列 + 打印任务解决
